# 5469-Natida

สวัสดีค่ะ หนูชื่อนางสาวณธิดา จิตจินดา มัธยมศึกษาปีที่สาม เลขที่ยี่สิบเอ็ด ออมสินค่ะ 

เวลาว่าง พูดถึงงานอดิเรกก็ชอบอ่านหนังสือเเละเขียนนิยายค่ะ เป็นชีวิตจิตใจเลย นอกจากนั้น ส่วนตัวชอบวาดรูปถ้าสมองเเล่นด้วยค่ะ มักจะเขียนนิยายในภาษาอังกฤษหรือเเปลนิยายอังกฤษเป็นไทยมาลงในรีดอะไรท์ เเต่ตอนนี้ปัจจุบัณตอนนี้เลย เว็ปที่ใช้ลงนิยายกำลังล่มค่ะ TT นั่งคิดยืนคิดนอนคิดว่าตอนนี้จะเอางานไปลงที่ไหน ถ้าเปิดเว็ปมาเเล้วงานหายนี่จะร้องไห้

เพลงที่ชอบมักจะเรียกได้ว่าตามความรู้สึกตอนนั้นเเลย เป็นคนฟังเพลงหลากหลายมากค่ะ คืออะไรเพราะก็ฟัง อะไรเข้าหูก็ฟัง เเต่ถ้าพูดถึงวงที่ชอบคือ HOZIER กับ ADELE จะชอบสองคนนี้เป็นพิเศษค่ะ ก็นะ เทสดูเเก่ เเต่เพลงเก่าๆเเบบนี้โดนใจมาก ลืมบอกไปว่าจริงๆหนูรับงานคอมมิชชั่นด้วยนะ งานคอมมิชชั่นประเภทงานเเปลกับงานเขียนงานวิจัย ก็จะนับหน้าเเละความยากง่ายของงานคิดเรทต่างกันไป ลูกค้าไม่ได้เยอะมาก เเต่ก็ชอบจะทำงานให้เขาค่ะ ยิ่งงานเเปลวรรณกรรมนี่ยิ่งชอบ วรรณกรรมงานดีทุกครั้งที่เเปลเลยยยย
